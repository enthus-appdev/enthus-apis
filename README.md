# enthus-apis

> **⚠️ This repository has been archived.**
>
> It contained the gRPC / protobuf definitions for the original internal API
> system, historically known as *Stargate*.
>
> It has been replaced by a new **HTTP-based Stargate**, built for greater
> flexibility in connecting to other services. Each service now exposes its
> own OpenAPI spec, so a separate definitions repository is no longer needed.

---
